## 核心結論（詳見 `docs/00-綜合分析報告.md`）

**爭點不在引文真偽，而在同一段文字的詮釋權。**

- 沈伯洋 2014 年《想想論壇》舊文**逐字屬實**（兩路獨立查證一致），作者欄由平台自身標註「本名沈伯洋」
- 但原文**全文無「美沙冬」三字、亦未點名任何國家**
- 「社區發毒品」字面上只對得上減害工具箱五層中的最上一層（海洛因輔助療法 HAT）；台灣實際執行的是第一層（針具交換）與第二層（口服替代療法）
- 綠營的「迴力鏖」在**文本層面未打中**（蔣萬安是提案人非連署、凍結標的不是美沙冬）；但藍營的**公衛反噬是真的**（疾管署長深夜發文、市府劃清界線、醫界大規模具名聲明）
- **醫界並非一面倒**：中華民國防疫學會具名反對減害論述，其反駁（依托咪酯非鴉片類、美沙冬不適用）在科學上比雙方政治發言更有說服力

### 核心概念謠誤（S-E22～S-E29，2026-10-06 新增）

> 前 21 項集中於法律條號與統計數字，卻漏了本場爭議**最核心的定義性謬誤**——把減害措施誤讀為「發毒品」。這才是選戰攻防的主要武器，故補列。

| 編號 | 謬誤 | 正確認義 |
|:--|:--|:--|
| S-E22 | 「清潔針具計畫＝發毒品」 | 只發針頭／注射水／稀釋液／回收盒，**不發任何物質**；官方定性「二害相權取其輕」 |
| S-E23 | 「安全注射室＝社區發毒品所」 | **完全不提供、不販售、不發放任何管制物質**，僅空間、醫護監測、拿破酮、轉介 |
| S-E24 | 「美沙冬就是拿來換毒品的」 | 處方治療藥，**每日當面口服、不可帶出**，非街頭發放 |
| S-E25 | 「拿破酮是縱容吸毒的毒品」 | **解毒劑**，不是毒品也不是鴉片類；有劑量反應關係之死亡預防證據 |
| S-E26 | 「除罪化＝政府合法販毒」 | 除罪化是**法律地位變更**，非管制放寬；葡萄牙同時設立勸戒委員會並擴張 OAT／NSEP |
| S-E27 | 「減害會讓更多人吸毒」 | CDC、WHO、國家科學院評估**均未發現**此效應 |
| S-E28 | 「台灣愛滋疫情因減害而惡化」 | 與官方數據**相反**（72%→約1.6%）；⚠️ 口徑差異見 §4.5 |
| S-E29 | 「HAT 就是社區發毒品」 | 須**專責診所、護士在場、每日 2–3 次親自到場服藥**，非街頭發放 |

> **S-E19 的意義**：這是搜尋引擎 AI 摘要**與官方原文相反**的實例。整份 repo 的方法論結論是：**選戰攻防中引用 AI 摘要的法律條號與統計數字，風險極高**。
>
> **S-E20、S-E21 的意義更值得記取**：這兩項**不是外部謠言，而是本 repo 初版自己的錯誤**，且其中一項被我當時稱為「整場爭議最實用、但被雙方忽略的發現」。經獨立 review 實際抓取法規原文後才發現論證前提不成立。→ **連「經過兩路獨立查證」的段落，仍可能在轉述與套用時出錯；每一層都需要回到原始文本驗證。**
