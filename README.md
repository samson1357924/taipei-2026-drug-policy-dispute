## 💡 成立初衷與呼籲 (Our Origin & Mission)

### 成立背景：公共討論空間的極端壓縮
在 2026 台北市長選戰爆發毒品與減害政策爭議期間，我們在 Threads、Facebook、PTT、X 等各大社群平台上，目睹了大量**「片面資訊、去脈絡化斷章取義、各取所需只挑對自家有利言論」**的政治動員與仇恨標籤（如「社區發毒品」、「毒販同路人」、「踐踏公衛」）。這種二元極化生態嚴重壓縮了台灣社會理性探討公共政策的空間，更掩蓋了當前真正致命的青年依托咪酯（喪屍煙彈）成癮危機。

### 探索嘗試：運用 AI 工具回歸事實
面對鋪天蓋地的混亂資訊，公民發起人嘗試運用現代前瞻 AI 研究與協同工具（如 OpenClaw、OpenCode、Codex 等），進行多智能體（Subagents）並行文獻調研、法規條文比對、立法院與疾管署歷史公報查核，跨出同溫層濾泡，尋找一手真實紀錄。

### 公開透明：呼籲各界恢復理性討論
我們決定將自身透過 AI 輔助與人工嚴謹複核所蒐集整理到的所有數據、法源矩陣、闢謠項目與文獻存檔，**透過 GitHub 開源 Repository 與公開互動網頁（GitHub Pages）全數無保留向社會公開**。  
我們無意為任何陣營辯護或定罪，而是誠摯拋磚引玉，**呼籲各方各界、各黨派幕僚、媒體與公民盡可能放下情緒與敵意，回歸第一手事實與科學證據，恢復健康、成熟且理性的公共政策討論。**

## 核心結論（詳見 `docs/00-綜合分析報告.md`）

**爭點不在引文真偽，而在同一段文字的詮釋權與政策事實的錯位。**

- 沈伯洋 2014 年《想想論壇》舊文**逐字屬實**（兩路獨立查證一致），作者欄由平台自身標註「本名沈伯洋」
- 但原文**全文無「美沙冬」三字、亦未點名任何國家**
- 「社區發毒品」字面上只對得上減害光譜最極端的**海洛因輔助療法（HAT）**；台灣實際執行的前兩層（針具交換、美沙冬替代療法）**都不發毒品**
- 藍營指控「沈伯洋主張在社區發毒品」為**後設推論**，非原文直接內容
- 綠營反控「蔣萬安連署美沙冬提案」在文本上亦**不成立**：立法院公報第 110 卷第 9 期載明蔣為**提案人**，且凍結標的為整條「強化藥癮治療服務」預算（100 萬元），提案中提及美沙冬僅為背景說明，未提議「刪除」或「禁止」美沙冬
- **醫界與公衛界並非一面倒**：支持綠營立場者有 30+ 醫療醫事團體聯合聲明；明確支持蔣萬安論述者有中華民國防疫學會（理事長王任賢）

## 核心分析工具：減害政策五層工具箱

| 層級 | 措施 | 物質交付？ | 台灣現況 | 涉及法源 |
|:---|:---|:---|:---|:---|
| **第一層** | 清潔針具計畫（NSEP） | ❌ 僅針具耗材，**不提供任何物質** | 全國實施（2005 試辦、2006 全國） | 《人類免疫缺乏病毒傳染防治及感染者權益保障條例》§8 |
| **第二層** | 鴉片類受體促效劑治療（OAT，美沙冬／丁基原啡因） | ⚠️ 醫用管制藥品，**當面口服、不發放** | 全國實施（2006 全國推動） | 同上法源及衛福部治療指引 |
| **第三層** | 鴉片類過量拮抗劑分發（拿破酮 Naloxone） | ❌ **解毒劑，非毒品** | 醫療院所備用；社區分發國外普及、台灣研議中 | 《藥事法》處方藥規定 |
| **第四層** | 藥物檢驗服務（Drug Checking） | ❌ 不發放物質；僅檢驗成分 | 台灣民間自發性倡議，**無官方試辦** | 涉及持有毒品之法律爭議 |
| **第五層** | 醫用海洛因輔助治療（HAT） | ⚠️ 醫療級海洛因（非街頭毒品），**專責診所由護士當面給藥** | 台灣**完全未引進**，亦無修法提案 | 涉及《毒品危害防制條例》第一級管制 |

> **「發毒品」的指控在字面上只對得上第五層。** 台灣目前實施的減害政策（第一層與第二層）**都不發毒品**。

| S-E04 | 「沈伯洋原文主張在社區發毒品」 | **後設推論**（原文主張除罪化＋管制，未提發毒品） |

| S-E08 | 「沈伯洋舊文主張效仿瑞士醫療海洛因」 | **無文本依據**（原文未點名任何國家） |
| S-E09 | 「沈伯洋舊文主張美沙冬」 | **無文本依據**（原文無美沙冬三字） |
| S-E10 | 「台灣體質不適合除罪化是當年主張」 | **時序錯置**（2014 原文將除罪化列為選項） |
| S-E11 | 「沈伯洋舊文介紹各國具體減害措施」 | **無文本依據**（全文未介紹特定國家措施） |

| S-E15 | 「減害已寫入現行反毒報告書」 | 無據（停編於民國 105 年） |
| S-E16 | 「台灣芬太尼喪屍入侵」 | 查無官方聲明 |
| S-E17 | 「台灣公共衛生聯合協會」為具名組織 | 查無此機構 |
| S-E18 | 「台灣藥癮戒治學會」為具名組織 | 未檢得（應為台灣成癮學會） |
| S-E19 | 「台灣無毒品查緝署」 | AI 摘要捏造 |
| S-E20 | 「依托咪酯占查獲重量 28.35%」 | **分母錯誤**（應為「占第二級毒品」；占全部重量實為約 4.94%，相差約 5.7 倍） |
| S-E21 | 「現行採尿並不檢測依托咪酯」 | **過度絕對＋法源錯置**（應為「預設／基本檢驗項目不含」；校園篩檢法源為《特定人員尿液採驗辦法》第 11 條） |
| S-E22 | 「清潔針具計畫＝發毒品」 | 只發針頭／注射水／稀釋液／回收盒，**不發任何管制物質**；官方定性「二害相權取其輕」 |
| S-E23 | 「安全注射室＝社區發毒品所」 | **完全不提供、不販售、不發放任何管制物質**，僅提供安全空間、醫護監測、急救拿破酮與戒治轉介 |
| S-E24 | 「美沙冬就是拿來換毒品的」 | 處方治療藥，**每日當面口服、不可帶出**，非街頭自由發放 |
| S-E25 | 「拿破酮是縱容吸毒的毒品」 | **解毒劑**，不是毒品也不是鴉片類；具顯著死亡預防實證 |
| S-E26 | 「除罪化＝政府合法販毒」 | 除罪化是**法律責任變更**，非管制放寬；葡萄牙同時設立勸戒委員會嚴加管理 |
| S-E27 | 「減害會讓更多人吸毒」 | CDC、WHO、美國國家科學院評估**均未發現**此效應 |
| S-E28 | 「台灣愛滋疫情因減害而惡化」 | 與官方數據**相反**（注射藥癮新增愛滋自 2005 年約 72% 降至約 1.6%） |
| S-E29 | 「HAT 就是社區發毒品」 | 須**專責診所、護士在場、每日 2–3 次親自到場服藥**，非街頭發放 |
